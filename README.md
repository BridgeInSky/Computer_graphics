# Computer_graphics

# Алгоритм Брезенхема — визуализация

Интерактивная веб-страница для наглядного изучения **алгоритма Брезенхема** —
классического алгоритма растровой отрисовки линий и окружностей, использующего
только целочисленную арифметику.

На странице можно:
- строить **отрезки** и **окружности** по алгоритму Брезенхема;
- менять цвет, координаты и радиус;
- сравнивать результат с «идеальной» фигурой, которую рисует сам Canvas;
- видеть количество закрашенных пикселей и шагов алгоритма.

---

## Что внутри

```
bresenham/
├── index.html      — веб-страница с интерфейсом
├── bresenham.js    — реализация алгоритма Брезенхема
└── README.md       — этот файл
```

- **`bresenham.js`** — содержит функции:
  - `bresenhamLine(ctx, x0, y0, x1, y1, color)` — рисует отрезок на Canvas;
  - `bresenhamPixels(x0, y0, x1, y1)` — возвращает массив пикселей отрезка;
  - `bresenhamCircle(ctx, xc, yc, r, color)` — рисует окружность на Canvas;
  - `bresenhamCirclePixels(xc, yc, r)` — возвращает массив пикселей окружности;
  - и их варианты для работы с `ImageData` (быстрая отрисовка).

- **`index.html`** — подключает `bresenham.js` и предоставляет интерфейс:
  вкладки «Отрезок» / «Окружность», поля ввода, палитру цвета и сам холст.

## Как запустить

Есть **два способа** — выберите любой.

### Способ 1. Просто открыть файл (самый простой)

1. Скачайте оба файла — `index.html` и `bresenham.js` — в **одну папку**.
2. Дважды кликните по `index.html`.

Страница откроется в браузере по умолчанию.

> **Если ничего не рисуется** или в консоли ошибка вида
> `Access to script ... has been blocked by CORS policy` — используйте Способ 2.

### Способ 2. Через локальный веб-сервер (рекомендуется)

Некоторые браузеры (особенно Chrome и Edge) блокируют загрузку локальных
`.js`-файлов, когда страница открыта по `file://`. Локальный сервер это решает.

#### Если установлен Python 3

1. Откройте терминал (командную строку) в папке с проектом.
2. Выполните:

   ```bash
   python -m http.server 8000
   ```

   или, если `python` не найден:

   ```bash
   python3 -m http.server 8000
   ```

3. В браузере откройте: **http://localhost:8000**

#### Если установлен Node.js

1. Откройте терминал в папке с проектом.
2. Выполните:

   ```bash
   npx serve
   ```

3. Перейдите по адресу, который покажет команда (обычно
   `http://localhost:3000`).

#### Расширение для VS Code

Если пользуетесь VS Code:

1. Установите расширение **Live Server**.
2. Откройте `index.html` в редакторе.
3. Нажмите правой кнопкой → **Open with Live Server**.

## Как пользоваться

На странице две вкладки — **Отрезок** и **Окружность**.

### Режим «Отрезок»

| Действие | Как |
|---|---|
| Задать начало отрезка | Поля **X₀ / Y₀** или **правый клик** по холсту |
| Задать конец отрезка | Поля **X₁ / Y₁** или **левый клик** по холсту |
| Поменять цвет | Палитра «Цвет» |
| Показать/скрыть сетку | Чекбокс «Показывать сетку» |
| Сравнить с идеальной линией | Чекбокс «Показывать идеальную фигуру» |
| Перерисовать | Кнопка «Нарисовать» |
| Очистить холст | Кнопка «Очистить» |

Панель справа показывает **количество пикселей** и **шагов алгоритма**.

### Режим «Окружность»

| Действие | Как |
|---|---|
| Задать центр | Поля **X центра / Y центра** или **левый клик** по холсту |
| Задать радиус | Поле **Радиус** или **правый клик** по холсту (радиус = расстояние от центра до клика) |
| Поменять цвет | Палитра «Цвет» |
| Сравнить с идеальной окружностью | Чекбокс «Показывать идеальную фигуру» |

Красная точка на холсте — **центр** окружности.

## Что можно попробовать сделать

- Нарисуйте линию под углом 45° и под углом 30° — обратите внимание,
  как «лесенка» пикселей отличается.
- Постройте окружность радиуса `1`, `2`, `5`, `10`, `100`, `250` — сравните,
  как меняется «пиксельность» контура.
- Включите «Показывать идеальную фигуру» и найдите места, где пиксельная
  фигура отклоняется от гладкой.
- Постройте вертикальную и горизонтальную линии — у них алгоритм
  заканчивает работу за минимальное число шагов.

## Как это работает (кратко)

**Идея алгоритма Брезенхема** — на каждом шаге двигаться к цели,
выбирая между двумя соседними пикселями и накапливая ошибку между
«идеальной» линией и её растровым приближением. Используется только
сложение, вычитание и сравнение — без операций с плавающей точкой.

Для **окружности** используется симметрия: вычисляется только 1/8 дуги,
остальные 7/8 получаются зеркальным отражением относительно осей
и диагоналей. Параметр `d` определяет, в какой момент нужно уменьшить `y`.

Подробнее — в комментариях к `bresenham.js`.

## Возможные проблемы

**Страница пустая, фигуры не рисуются**
- Откройте консоль браузера (F12 → Console) и посмотрите текст ошибки.
- Если ошибка про загрузку `bresenham.js` — запустите через локальный
  сервер (см. Способ 2).
- Если ошибка `bresenhamCircle is not defined` — проверьте, что файл
  `bresenham.js` лежит рядом с `index.html` и в нём нет синтаксических
  ошибок.

**Изменения не применяются после правки `bresenham.js`**
- Обновите страницу с очисткой кэша: **Ctrl + F5** (Windows/Linux)
  или **Cmd + Shift + R** (macOS).

**Браузер открывает файл, но вместо страницы показывает текст**
- Убедитесь, что открываете именно `index.html`, а не `bresenham.js`.
